# 界面与体验规范

「通识卡」的界面主要服务成人快速阅读和引导线下亲子对话。视觉目标是温暖、人文、轻盈、克制；清晰的阅读层级优先于装饰。当前是项目导览首页，下面的课程交互属于未来设计要求，并非已实现功能。

## 白皮书视觉基线

| 用途 | 色值 |
| --- | --- |
| 背景暖米灰 | `#F9F9F7` |
| 卡片白 | `#FFFFFF` |
| 自然与生命 | 森林绿 `#3C825B` |
| 社会与文明 | 丹宁蓝 `#356AC3` |
| 科技与造物 | 琥珀橙 `#E67E22` |
| 思维与逻辑 | 星云紫 `#7D5BA6` |
| 艺术与心智 | 珊瑚粉 `#D96B6B` |

白皮书建议卡片 16px 圆角、柔和弥散阴影；实际以内容层级为先，避免每个区块都加框。颜色是主题识别而非唯一信息渠道，文字和图标须共同表达类别与状态；主题色未必适合白底小字或白字按钮，须逐组合检查对比度，不达标时调整前景或背景，而不是更改分类含义。现有项目变量见 `tokens.css`。

## 成人阅读与可访问性

- 标题、问题、话术和安全提示形成清晰层级；正文建议至少 16px、舒适行高，允许系统字体缩放与页面滚动，不用固定高度裁剪。
- 普通文本与背景对比度目标至少 4.5:1；大字至少 3:1，图形及控件边界至少 3:1。以实际前景/背景组合核对，而非假设所有主题色均达标。
- 交互目标至少 44×44 CSS px，留有间距；图标按钮有明确文字或无障碍名称，状态不只靠颜色。H5 支持键盘操作、可见焦点与语义标签；小程序使用对应的无障碍属性并检查读屏顺序。
- 兼顾窄屏、横竖屏、较大字号、顶部/底部安全区与长文本；不依赖悬停。减少动态效果并尊重系统减少动态效果设置，状态变化清楚、不阻断操作。
- 未来卡片可提供展开分支，安全警示不能被默认折叠或为了单屏省略。文字记录和照片等可选功能需有明确权限说明和取消途径，见[儿童安全](../security/child-safety.md)。

## 无焦虑交互

用“继续探索”“下次再聊”而非失败、落后、惩罚性断签；允许跳过、暂停和回看。星级如最终采用，只描述自愿活动状态，不代表孩子能力，也不与其他家庭比较。设计时优先照顾成人理解和儿童差异，而非追求打卡频次。未来三栏信息架构见[产品概览](../product/overview.md)。
