# 微探究卡片规范

适用未来的家长引导卡和周末实践；当前并无已发布卡片。按[课程结构](curriculum.md)映射世界、篇章、大概念和适龄阶梯，先确定家庭场景与开放问题，再安排观察、分支和成人知识补充。

## 内容与长度

目标正文 200–300 字，方便成人快速阅读，而非用长度取代质量。计数口径：将展示给家长的正文各段（场景、提问、两个分支、点拨、观察及安全提示、成人知识）拼接，按 Unicode 字符计数，包含中文、标点、数字和空格，不计换行、标题、标签、元数据及来源；英文字母逐字符计。记录实际数量，超出范围时编辑说明原因。安全、科学准确和可读性优先于字数与“一屏”；内容可滚动，不能为了塞进一屏删掉必要安全提示。

卡片用常见场景、开放提问和可执行的观察，不以二元对错收尾。约 30 秒是**当下观察或动作**的目标，不保证自然变化完成：例如植物染色可能需要数小时甚至更久，须写清准备、预计等待与可能无明显结果，不能称为 30 秒完成；也可改成观察事先由成人准备的样本。观察无变化同样是有效结果。

## 结构化字段合同

以下为内容生产合同，不声称已有数据模型或接口。字段使用稳定名称；非空文本须能独立理解，`sources`、`reviews` 为列表，生命周期及责任人可追溯。

| 字段 | 要求 |
| --- | --- |
| `id`、`version` | 唯一稳定标识和修订版本 |
| `world`、`chapter`、`concept`、`ageBand` | 使用课程规范中的名称和一个主要概念 |
| `title`、`question`、`scene` | 家长可读的标题、开放问题和日常场景 |
| `opening` | 可直接说出的破冰话术 |
| `ifUnsure`、`ifImaginative` | 答不出时给线索；想象性回答时先接纳、再一起观察，不嘲笑或直接判错 |
| `explanation`、`adultNote` | 分龄点拨与科学准确的成人补充；类比不冒充事实 |
| `observation` | 材料、操作、即时观察时长、等待时长及不明显时的回应 |
| `safety` | 监护、限制、风险替代及可随时停止的提示；无风险也要说明审查结论 |
| `sources` | 每条含来源名称、可访问链接或出版信息、支持的具体主张及查阅日期 |
| `reviews` | 审校类型、审校人、日期、版本、结论及必要修改记录 |
| `status` | 下述生命周期状态 |

周末实践沿用上述字段，另明确准备材料、步骤、成人职责、预计主动操作与等待时间、替代或退出方式；不强制按日常卡片长度压缩。

## 填写模板

```text
id / version：
world / chapter / concept / ageBand：
title / question / scene：
opening：
ifUnsure：
ifImaginative：
explanation / adultNote：
observation（材料、步骤、观察与等待时间、无明显变化怎么办）：
safety（监护、风险、替代、停止）：
sources（来源、主张、日期）：
reviews（角色、人员、日期、版本、结论）：
status：草稿
```

模板用于创作时填写，不是可发布内容。审校流程：**草稿 → 待审 → 修改中/待复审 → 已签发 → 已发布 → 已撤回**；未通过回到修改中，实质修改后重新审校，记录科学、儿童安全与编辑审校及人工签发，撤回保留原因和版本历史。来源不足、风险无法控制或解释不准确不得签发；发布和撤回机制尚未实现。

## 白皮书风险素材处理

- 镜中可见舌面小凸起主要是舌乳头，味蕾分布在部分乳头内，通常不能靠肉眼直接看到；不要把可见红点称作味蕾。
- 水蒸气是看不见的气体；通常看到的白雾是冷凝形成的小水滴。不要为观察雾气让孩子接触热水或蒸汽，可观察日常安全的窗面凝露。
- 不盲尝未知食材，不强迫闻、摸或吃；考虑过敏、卫生与窒息风险。不要让孩子直接持冰，可由成人将冰放在透明容器内观察融水。
- 不要求触摸动物、羽毛或投喂野生动物；从安全距离观察或使用图片。避免接触不明植物和污染物；不揉碎不明落叶。任何活动都应在监护人陪伴下可暂停。

更完整的红线见[儿童安全](../security/child-safety.md)。
