## 使用与领取边界

- 适用对象仅为 3–5 岁儿童的家长。活动支持线下对话，不是感官、能力、健康或发育测验；不要求答对、坚持参与或完成全部步骤。
- 按个人访问领取：同一北京时间日反复打开仍是同一张，新的访问日领取目录中下一张未领卡。未访问的日期不补发。
- 保留全部稳定 ID；`w01`／`w02` 是已有内部 ID，不根据前缀推断实践类型。新增内容追加目录，不改变已有 ID 的含义。
- 实践是内容类型而非周末派发限制；领取顺序不因访问星期而跳过或重排。
- 微信云端保存领取日与卡片 ID，左滑回看已领取历史、右滑返回较新卡片。全部领取后保留历史，不循环旧卡冒充新卡。
- 正面是提问与互动，必要操作条件融入活动正文；背面是供家长使用的说明。实践另列材料、成人准备、操作／等待时间和三步活动；长内容可滚动，不为一屏省略操作条件。界面不单列流程状态或提示区，真实内容状态保留在本文件。
- 约三十秒只适用于部分当下观察，不是所有活动总时长。四张实践的设计操作约 3–5 分钟，准备、等待与清理另计；时长未经过家庭实测，不保证现象出现。
- 成人先检查材料与场地。不盲尝、不强迫闻摸、不蒙眼、不掐皮肤、不直接持冰、不接触热水蒸汽，不在洗澡、道路或水边分心看手机；不舒服、不愿参与或材料不适合即停，可只看图片或由成人示范。
- 对话方法由观察、描述逐步延伸到猜想和比较，不要求每天完成前一天的活动。正面补充可选追问或孩子的选择，并允许现象不明显、结果相同或不愿继续；孩子也可以指认、用动作回应或听成人描述。这些方式尚需家庭实测，不能当作趣味、效果或分龄适宜性的审校结论。

## 周末实践的执行边界

完整材料与步骤以数据源和卡片背面为准；以下是审校重点，不是额外实践：

- `d02`：只用已知不过敏的熟悉水果，成人清洗、拿稳；先看后自愿自然闻，不切剥、不深吸、不盲尝。绘画为可选，笔与笔帽由成人管理。
- `d03`：主要观察自己的手，皮肤不适时可看手部图片；成人画轮廓仅供可选的手指指认，不假设轮廓画出了纹路或关节。不拉扯、不掐捏，不比较身体是否“正常”；使用纸笔时由成人检查和收好。
- `d08`：成人事先冷藏一瓶水，再与常温密封塑料瓶对比；不冰冻，不使用玻璃、热水、冰块或蒸汽。冷却与现象等待另计；看到水珠时再讨论凝结，没看到时如实描述并说明可能与温湿度有关，洒水及时擦干。
- `d09`：成人选择轻质、无尖边容器并扶稳，远离灶台和热食，只轻敲、不靠耳，不使用玻璃陶瓷；不适立即停止。声音还受形状、大小与敲击等影响，不把一次比较变成材质定律。
- `d10`：先观察水滴形状和位置，有移动或碰面才讨论变化；无雨或看不清时可看静态图片，不用图片假设发生了碰面。
