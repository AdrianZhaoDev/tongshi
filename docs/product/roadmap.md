# 首版决策与发布条件

## 已确认的范围

| 事项 | 决策 |
| --- | --- |
| 受众 | 只做 3–5 岁儿童的家长，不提供年龄选择或能力判断 |
| 界面 | 一页一张主角卡片；无地图、用户资料、金句、打卡、设置或底栏 |
| 视觉 | 使用首选「暖杏米白」；主程序不显示配色或演示状态切换器 |
| 交互 | 点击看正反面；右滑回看已看历史，左滑返回较新历史或今日；首尾不循环 |
| 今日内容 | 设备当地日期匹配显式排期，每天固定一张；不随机、不提前解锁 |
| 历史 | 只包含往日打开过的日卡；跳过的日期不自动补入 |
| 状态表达 | 仅有内容日期与必要边界，不显示页码、卡库总数、完成率或排名 |
| 数据 | 本机只保存已看日期与卡片 ID；不采集儿童文字、照片、声音，不上传或同步 |
| 订阅 | 真实接口未配置时按钮不可用，不显示虚假授权或发送成功 |

## 当前内容与本地排期

已有 12 张未审草稿，按 `src/domain/cards.ts` 的日期逐日显示。它不是已签发课程，也不等于连续 14 天所需的内容。排期结束后不循环旧卡冒充新卡。完整内容与安全改写见[内容草稿](../content/first-version-plan.md)。

## 正式发布尚需的外部条件

- 逐卡补全可核实依据，完成科学事实、儿童安全与编辑人工审校及有权限者签发；不能由 AI 自我批准。
- 确认生产发布日期与完整内容供应；本地设备日期不是可信服务端发布时钟。
- 使用自有微信 AppID 配置有效订阅模板、用户授权和服务端定时发送；AppSecret 只保存在服务端。
- 在微信开发者工具与真机验证卡堆手势、字号、系统动态偏好、读屏、安全区、存储错误与日期切换；双端构建通过不是该验证的替代品。
- 核验正式平台的隐私说明、框架行为与本机历史保留要求。
