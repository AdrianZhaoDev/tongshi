# 首版决策与发布条件

## 已确认的范围

| 事项 | 决策 |
| --- | --- |
| 受众 | 只做 3–5 岁儿童的家长，不提供年龄选择或能力判断 |
| 界面 | 一页一张主角卡片；无地图、用户资料、金句、打卡、设置或底栏 |
| 视觉 | 使用首选「暖杏米白」；主程序不显示配色或演示状态切换器 |
| 交互 | 点击看正反面；左滑回看已领取历史，右滑返回较新卡片；首尾不循环，无历史时提示「明日再来哦」 |
| 今日内容 | 北京时间同日只领取一张，按目录顺序领取下一张未领卡，不绑定内容日期 |
| 历史 | 仅包含实际访问领取的卡片；缺席不补发，全部领完保留历史 |
| 状态表达 | 领取不是完成，不显示完成率、能力评分或排名 |
| 数据 | 微信平台身份关联云端领取日期与卡片 ID，跨设备共享；H5 为本地预览，旧本地历史不自动上传；不采集儿童资料 |
| 订阅 | 微信原生授权后保存云端计划；缺配置、拒绝或未确认时不冒充成功；H5 不提供提醒 |
| 频率 | 长期默认未勾选；未勾选仅一次，勾选可选每日／每 2 日／每周，初始每日；首次次日北京时间 09:00 |
| 内容数量 | 14 张未审草稿，含 10 张日常卡与 4 张实践卡，稳定 ID 不变 |

## 当前内容与领取顺序

已有 14 张未审草稿，以 `cloudfunctions/reminders/cards.json` 为唯一内容源，前端类型入口为 `src/domain/cards.ts`。每个新的访问日领取下一张未领卡，与固定日期、星期脱钩；领完后不循环旧卡冒充新卡。实践背面保留材料、成人准备、操作／等待时间和步骤；内容与安全边界见[内容草稿](../content/first-version-plan.md)。

微信云端进度与提醒代码尚未部署。默认支持一次与长期两种提醒策略，真实模板类别及有效授权仍由微信决定；不自动从长期降级一次。发送时读取该用户下一张未领卡的标题，提醒不代领卡；全部领取后不再发送。新计划替换旧计划，未知发送结果不重发；停止不能撤回在途消息。详细部署与限制见 [README](../../README.md#微信提醒配置与部署)。

## 正式发布尚需的外部条件

- 逐卡补全可核实依据，完成科学事实、儿童安全与编辑人工审校及有权限者签发；不能由 AI 自我批准。
- 确认内容供应与人工签发；服务端北京时间仅用于每日领取去重，不是内容发布批准。
- 配置自有微信 AppID、真实云环境、账户具备资格的模板及其字段，部署 `reminders` 云函数、进度／提醒集合规则、索引和定时器；模板必须包含下一张卡片标题。不要在前端放置 AppSecret。
- 在微信开发者工具与真机验证卡堆手势、字号、系统动态偏好、读屏、安全区、网络错误、跨设备进度与北京时间切日；双端构建通过不是该验证的替代品。
- 核验正式平台隐私说明、框架标识、云端领取进度及微信身份／提醒状态的保留和删除流程；停止提醒不删除进度或用于幂等的回执。
