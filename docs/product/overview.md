# 产品概览 · 每日单卡

## 定位

通识卡只服务 3–5 岁儿童的家长：每天用一张简短提问和互动建议支持线下亲子交流。已选视觉为「暖杏米白」，内容是交谈提示，不是儿童能力、健康或发育评估。

## 已确定的界面与规则

- 主页进入即领取个人当日卡片，另有只读卡片分享页；无地图、账号表单、年龄选择、手账、输入记录、打卡或底栏。
- 正面包含标题、场景、开放提问和随手互动，必要操作条件融入正文；实践卡背面另列材料、成人准备、操作／等待时间与步骤。字号放大或内容较长时允许阅读滚动，不为一屏省略操作条件；界面不单列提示区、审校流程标签或免责式备课说明。
- 按北京时间划分领取日，同一天反复打开仍是同一张；下次访问新的日期才领取下一张，缺席不补发。卡片内容不绑定发布日期或星期。
- 左滑回看已领取历史，右滑返回较新卡片；没有历史时左滑提示「明日再来哦」。全部领取后不循环或承诺明日有新卡。
- 微信以平台身份识别用户，云端事务保存领取日期与卡片 ID，跨设备共用个人进度；领取不表示完成活动或掌握知识。H5 只是本地预览，不同步微信进度。订阅需另行自愿授权，不新增儿童资料、手机号或注册。
- 分享当前正在看的卡片，包括已领取历史。微信好友打开稳定 ID 链接即可查看完整内容；分享阅读不领取、不改变个人进度、不携带用户身份。无效链接提示重新发送，只有主动进入主页才按正常规则领取。分享标题仅含产品名称和卡片名称，分享页沿用正文展示规则；H5 仅供页面预览，真实审核状态记录于[内容文档](../content/first-version-plan.md)。

## 当前交付边界

正式 uni-app 入口采用已选视觉及跨端卡堆；原始 HTML 预览仅作历史视觉对照，不是小程序运行容器。现有 14 张内容仍是未审草稿，按内容目录顺序领取，包含 10 张日常卡与 4 张实践卡；稳定 ID 不变，不再绑定日历排期。

微信提醒的原生授权、云端保存、停止和定时发送代码已实现，尚未配置真实账号、环境、模板或部署。长期默认未勾选，只安排一次；勾选后可选每日、每 2 日、每周。首次为次日北京时间 09:00，实际送达受轮询与平台影响；发送时读取个人下一张未领取卡片标题，发送本身不推进进度，全部领取后不再发送新卡提醒。

微信好友卡片分享代码已接入，使用原生转发和默认页面截图；朋友圈与保存相册不在本次范围。未接入服务端内容发布、账号表单、支付或在线 AI。微信云端进度读取失败不退回本地假进度；旧本地历史不自动上传覆盖云端。H5 不模拟微信授权或分享成功；未知发送结果不盲重试，停止不会召回在途消息或删除幂等记录。开发者工具、真机、正式隐私说明与内容人工签发仍是独立闸门。

实际运行方式及数据边界以 [README](../../README.md) 为准。
