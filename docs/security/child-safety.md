# 儿童安全与数据保护

本项目面向监护人和儿童共同使用；当前初始化不提供儿童资料采集、账户、上传、在线 AI 或后端。以下是未来设计的最低要求，不构成法律合规保证。涉及实际收集、地区、平台政策或第三方处理前，须由负责人结合适用要求与专业意见评审。

## 内容与活动安全

活动由监护人陪伴，选择适龄、安全、可随时中止的替代方式；不要求孩子独自操作危险物品。不盲尝、不接触热水或蒸汽、不直接持冰、不触摸或投喂动物，避免不明植物、过敏源、尖锐易碎物及污染物。发现不适立即停止；不把风险素材照搬成课程。科学修正与实践细节见[卡片规范](../content/card-standard.md)。

## 最小采集与监护人控制

- 功能不需要的数据不收集；避免真实姓名、精确生日、学校、地址、位置、健康信息等，必要性须逐项说明。开发和验收使用虚构且不可关联真实儿童的数据。
- 任何儿童资料、照片、语音的收集、保存、处理或分享之前，向监护人清晰说明目的、范围、保存期限、接收方和风险，并取得适用的有效同意；拒绝不应妨碍无关功能。不得将发布或分享设为默认。
- 照片、语音可能包含人脸、声音、环境、地点等识别信息；优先不采集，确需处理时先做数据最小化与脱敏，去除非必要元数据，限制访问和传输。脱敏并不保证无法重新识别。
- 提供监护人可操作的查看、撤回同意与删除途径；设计时覆盖本地、服务端、第三方及备份的删除或过期安排，说明处理期限、例外和状态。未来实现前决定具体保存期和责任人，不声称这些机制已存在。
- 只收集完成明确目的所需信息，传输和存储采用与风险相称的保护措施，限制访问、设定保留期限、记录处理责任；审查第三方的数据用途和删除能力。

## AI 与密钥边界

未来如考虑 AI，先完成用途、供应商、数据流、监护同意和安全评审，默认不发送儿童身份信息、照片或语音。AI 只能提供待人工审阅的教育性引导，不作医疗、心理或发育诊断，不对儿童能力评分或排名，不替代专业人员；遇健康担忧应建议联系合适的专业人员。不得自动发布生成内容，按[AI 工作流](../ai/workflow.md)人工签发。任何服务密钥只放服务端受控环境，不放小程序、H5 包、代码仓库或日志；当前没有密钥服务。
